# Visual generators

Every diagram and chart in `assets/` is generated by code in this folder. Nothing is hand-drawn, so the visuals stay consistent and can be rebuilt after a change.

| File | Builds |
|---|---|
| `svgkit.py` | Shared palette, type and drawing helpers |
| `diagrams.py` | Banner, stats strip, architecture, hierarchy, event flow, checkout flow, CI/CD |
| `charts.py` | Commit activity chart and the code and tests chart |
| `data/stats.json` | Counts taken from the git history of the `dev` branches |

## Rebuild

```bash
pip install matplotlib
python tools/diagrams.py assets
python tools/charts.py assets tools/data/stats.json
```

The charts use the Inter font if it is installed. Text in the charts is converted to outlines, so the SVGs look the same on every machine.

The palette was checked for colour-blind safety and contrast against the dark background.
